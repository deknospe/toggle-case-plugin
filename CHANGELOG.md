# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and

## [Unreleased]

## [1.0.0] - 2026-07-29

### Added

- Upper, lower, title, camel, Pascal, snake, and kebab case conversions.
- Multi-caret selection support.
- Locale-independent Unicode conversion rules.
- JUnit 5 regression tests.
- GitHub Actions build and Dependabot configuration.

### Changed

- Reworked the original single action into an extensible conversion engine.
- Reorganized plugin actions under **Edit → Convert Case**.
- Updated project metadata and documentation.

## [0.0.2] - 2024-12-25

### Added

- Integration with the IntelliJ undo and redo history.

## [0.0.1] - 2024-12-25

### Added

- Initial toggle-case action.
